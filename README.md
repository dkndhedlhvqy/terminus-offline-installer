# Terminus — Free Offline Installer

![Category](https://img.shields.io/badge/SSH_Client-blue?style=flat-square)

## About

Terminus (formerly Tabby) is a free, open-source, cross-platform terminal emulator and SSH client for Windows, macOS, and Linux. Features GPU-accelerated rendering, tabbed and split-pane sessions, SSH connection manager, SFTP file browser, serial port support, and extensive theme customization. Terminus aims to modernize the terminal experience while supporting professional SSH workflows.

## Common Problems & Limitations

- **Resource Usage** — Electron/Rust-based; higher RAM usage than lightweight terminal emulators
- **Performance** — GPU rendering helps but heavier than native terminal apps like iTerm2
- **Plugin Ecosystem** — Growing but smaller than established terminal alternatives
- **Configuration Depth** — Extensive customization options require time to configure optimally
